Who I Am

I'm an Electronics & Communication Engineering student who found a stronger pull toward backend and full-stack development than circuits. Instead of just following tutorials, I built a real system end-to-end: authentication, role-based access, borrow/return logic, overdue tracking, and an admin panel — all wired to a MySQL database through raw JDBC and Servlets, no framework shortcuts.

That "build it properly, understand every layer" approach is how I learn. I'm now working through Striver's A2Z DSA Sheet to improve my problem solving skills daily and preparing Spring Boot to bring my stack up to industry standard for full-stack Java roles.

Library Management System
Primary Project

A full-stack library system built from scratch — no boilerplate templates — covering the complete lifecycle of book management with real authentication and role-based access.

  • Book CRUD, borrow/return logic, and automated overdue tracking
  • Session-based authentication with BCrypt password hashing
  • Role-based access control separating Admin and Member views
  • Dark, Spotify/Netflix-inspired UI built with React + Vite
  • Deployed on Apache Tomcat with a Maven-managed build
